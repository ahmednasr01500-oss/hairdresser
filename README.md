# أخضر — مِتنَقّي بالوَاحدَه 🌿

تطبيق موبايل لطلب الخضار والفاكهة من محل **أخضر** بالمنصورة، مع لوحة تحكم
ويب لصاحب المحل.

> **أول مرة تشتغل عليه؟** اقرا [SETUP.md](SETUP.md) — فيه ٧ خطوات لازم تتعمل
> في Firebase Console قبل ما التطبيق يشتغل بالكامل.

---

## المكوّنات

| الجزء | إيه هو | لمين |
|---|---|---|
| `lib/` | تطبيق Flutter (أندرويد + iOS) | العميل |
| `hosting/index.html` | صفحة تحميل التطبيق | لينك تبعته للزباين |
| `hosting/admin/index.html` | لوحة تحكم — صفحة HTML واحدة | صاحب المحل |
| `firebase/` | قواعد الأمان + بيانات البداية | مرة واحدة عند التركيب |
| `deploy.ps1` | بناء + نسخ الـ APK + نشر | أمر واحد لكل نشرة |

بعد النشر:

- **صفحة التحميل:** <https://akhdar-89577.web.app>
- **لوحة التحكم:** <https://akhdar-89577.web.app/admin/>

## اللي التطبيق بيعمله

- تصفّح الأصناف بالأقسام، بحث عربي بيتجاهل الهمزات والتشكيل، وفلاتر فرعية.
- سلة بتفضل محفوظة لو التطبيق اتقفل، وبتشيل الأصناف اللي خلصت لوحدها.
- طلب بالدفع عند الاستلام، مع كود خصم واختيار وقت التوصيل.
- عناوين متعددة، وتحديد الموقع على خريطة (OpenStreetMap — مجانية، من غير مفتاح API).
- تتبّع الطلب لحظيًا: أول ما صاحب المحل يغيّر الحالة، العميل يشوفها.
- شغّال بدون نت للتصفّح — الكتالوج متخزّن على الجهاز.

## اللي اللوحة بتعمله

- طلبات لحظية مع **صوت تنبيه** لأول ما يوصل طلب جديد، وعدّاد في عنوان الصفحة.
- إدارة الأصناف والأقسام والبانرات وأكواد الخصم.
- رفع صور بضغط تلقائي في المتصفح (Firebase Storage مش متاح مجانًا).
- إعدادات: فتح/قفل المحل، رسوم التوصيل، الحد الأدنى، العملة، إعلان للعملاء.
- اتصال وواتساب وفتح موقع العميل على الخرايط بضغطة.

## قرارات معمارية تستاهل التسجيل

- **الدخول بالاسم والرقم من غير OTP.** رسايل التحقق في Firebase محتاجة خطة
  Blaze وبتتكلّف على كل رسالة، وزباين محل الخضار مش هيستحملوا خطوة زيادة.
  تحت السطح بيتعمل تسجيل دخول مجهول عشان يبقى فيه `uid` تربط بيه الطلبات
  وقواعد الأمان تشتغل.
- **الصور base64 جوه قاعدة البيانات.** Firebase Storage بقى محتاج فوترة.
  اللوحة بتضغط الصورة لـ ٥٠٠ بكسل بجودة ٧٢٪ (حوالي ٢٥ كيلوبايت) وتخزّنها كـ
  data URL. مناسب لكتالوج محل؛ لو الكتالوج كبر أوي نحوّل لاستضافة صور.
- **خرايط OpenStreetMap مش Google Maps.** مجانية بالكامل ومش محتاجة مفتاح API
  ولا تفعيل فوترة. التغيير لو احتاجنا محصور في `lib/screens/map_picker.dart`.
- **العملة والتوصيل والحد الأدنى في قاعدة البيانات مش في الكود.** صاحب المحل
  يغيّرهم من اللوحة من غير نسخة جديدة من التطبيق.
- **حساب التوصيل والخصم في مكان واحد** (`AppSettings.deliveryFor` و
  `Coupon.discountOn`) عشان السلة والمراجعة والطلب النهائي ما يختلفوش أبدًا.
  دي أكتر حتة اتغطّت باختبارات.

## هيكل قاعدة البيانات

```
settings              إعدادات المحل — عقدة واحدة
categories/{id}       الأقسام
products/{id}         الأصناف
banners/{id}          بانرات الشاشة الرئيسية
coupons/{CODE}        أكواد الخصم (المفتاح هو الكود نفسه)
orders/{id}           الطلبات
user_orders/{uid}/{orderId}   فهرس طلبات كل عميل
customers/{uid}       بيانات العميل وعناوينه
counters/orderNumber  عدّاد أرقام الطلبات القصيرة
admins/{uid}          مين صاحب المحل — بتتكتب من الـ Console بس
```
